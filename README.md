# 行政处罚文档生成工具

基于 Python 的行政处罚决定书批量生成工具，替代原有的 VBA 方案。

## 功能特点

- ✅ **占位符模板**：使用 `{{字段名}}` 代替书签，肉眼可见，不易出错
- ✅ **配置驱动**：通过 JSON 配置文件管理，无需修改代码
- ✅ **数据验证**：自动检查模板和数据，提供详细的错误提示
- ✅ **批量生成**：支持一次生成多个文档
- ✅ **灵活命名**：支持自定义输出文件名格式
- ✅ **日志记录**：详细的生成日志，便于排查问题
- ✅ **跨平台**：支持 Windows、Linux、macOS

## 目录结构

```
行政处罚生成工具/
├── generate.py          # 主程序
├── config.json          # 配置文件
├── 模板文件/            # 存放 Word 模板
│   └── 行政处罚.docx
├── 信息文件/            # 存放 Excel 数据
│   └── 数据.xlsx
└── 输出文件/            # 生成的文档输出目录
```

## 快速开始

### 1. 安装依赖

```bash
pip install docxtpl pandas openpyxl
```

### 2. 准备模板

在 `模板文件/` 目录下创建 Word 模板，使用 `{{字段名}}` 作为占位符：

```
行政处罚决定书

案号：{{案号}}
当事人：{{当事人名称}}
案发地点：{{案发地点}}

违法事实：
{{违法事实}}

处罚决定：{{处罚决定}}

生成日期：{{生成日期}}
```

### 3. 准备数据

支持**两种数据布局格式**，程序会自动识别：

#### 格式一：水平布局（传统方式）
单 Sheet，每行一个案件，表头与模板中的占位符对应：

| 案号 | 当事人名称 | 案发地点 | 违法事实 | 处罚决定 |
|------|-----------|---------|---------|---------|
| 2024-001 | 张三 | 北京市 | 违法建设 | 罚款50000元 |
| 2024-002 | 李四 | 上海市 | 违规施工 | 罚款20000元 |

**生成示例数据：**
```bash
python create_sample_data_horizontal.py
# 输出：信息文件/数据_水平布局.xlsx
```

#### 格式二：垂直布局（推荐✓）
**每个案件一个 Sheet**，两列格式（字段名 | 值），编辑更紧凑：

**Sheet: 2024-001**

| 字段名 | 值 |
|--------|-----|
| 案号 | 2024-001 |
| 当事人名称 | 张三 |
| 案发地点 | 北京市 |
| 违法事实 | 违法建设 |
| 处罚决定 | 罚款50000元 |

**Sheet: 2024-002**

| 字段名 | 值 |
|--------|-----|
| 案号 | 2024-002 |
| 当事人名称 | 李四 |
| ... | ... |

**垂直布局优势：**
- ✅ 单个案件信息紧凑，无需横向滚动
- ✅ 每个案件独立 Sheet，切换方便
- ✅ 字段名和值对照清晰，不易出错
- ✅ 适合字段较多的复杂案件

**生成示例数据：**
```bash
python create_sample_data_vertical.py
# 输出：信息文件/数据_垂直布局.xlsx
```

### 4. 运行程序

```bash
python generate.py
```

或在 Windows 上双击运行（打包后）。

## 配置说明

编辑 `config.json` 文件：

```json
{
  "template_file": "模板文件/行政处罚.docx",
  "data_file": "信息文件/数据.xlsx",
  "output_dir": "输出文件",
  "filename_template": "{案号}_{当事人名称}_行政处罚决定书.docx",
  "sheet_name": 0,
  "skip_rows": 0
}
```

| 配置项 | 说明 | 示例 |
|--------|------|------|
| `template_file` | 模板文件路径 | `模板文件/行政处罚.docx` |
| `data_file` | 数据文件路径 | `信息文件/数据.xlsx` |
| `output_dir` | 输出目录 | `输出文件` |
| `filename_template` | 输出文件名模板 | `{案号}_{当事人名称}.docx` |
| `sheet_name` | Excel 工作表索引或名称 | `0` 或 `Sheet1` |
| `skip_rows` | 跳过的行数（表头前） | `0` |

### 文件名模板可用变量

- `{案号}` - 使用案号字段
- `{当事人名称}` - 使用当事人名称
- `{生成日期}` - 使用当前日期
- 任何 Excel 中的字段名都可以使用

## 占位符语法

### 基本用法

在 Word 模板中使用双大括号包裹字段名：

```
当事人：{{当事人名称}}
案发时间：{{案发时间}}
```

### 系统变量

以下变量会自动填充，无需在 Excel 中提供：

- `{{生成日期}}` - 当前日期（2024年01月15日）
- `{{生成时间}}` - 当前时间（2024-01-15 14:30:00）
- `{{年份}}` - 当前年份（2024）

### 高级语法（Jinja2）

支持条件判断：

```
{% if 性别 == '男' %}
先生
{% else %}
女士
{% endif %}
```

支持循环：

```
涉案人员：
{% for person in 涉案人员 %}
{{ loop.index }}. {{ person.姓名 }}
{% endfor %}
```

| 跨平台 | ❌ 需 Office | ✅ 纯 Python |

## 打包为可执行文件

使用 PyInstaller 打包为独立的 EXE 文件：

```bash
# 安装 PyInstaller
pip install pyinstaller

# 打包（无控制台窗口）
pyinstaller -F -w --icon=icon.ico generate.py

# 或保留控制台窗口（便于查看日志）
pyinstaller -F --icon=icon.ico generate.py
```

打包后的文件在 `dist/` 目录下，可直接双击运行。

## 常见问题

### Q: 模板中的占位符没有被替换？

A: 检查以下几点：
1. 占位符格式是否正确：`{{字段名}}`（注意是双大括号）
2. Excel 中的字段名是否与占位符完全一致（包括空格）
3. 查看 `生成日志.txt` 了解详细错误信息

### Q: 如何添加新的字段？

A: 
1. 在 Excel 中添加新列
2. 在 Word 模板中添加 `{{新字段名}}`
3. 无需修改代码，直接运行即可

### Q: 支持哪些 Excel 格式？

A: 支持 `.xlsx` 和 `.xls` 格式。

### Q: 如何生成不同的文件名？

A: 修改 `config.json` 中的 `filename_template`，例如：
- `"{案号}.docx"` - 仅用案号
- `"{当事人名称}_{生成日期}.docx"` - 当事人+日期
- `"行政处罚决定书_{案号}.docx"` - 固定前缀+案号
